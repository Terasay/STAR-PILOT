# STAR PILOT — прототип полёта

Unity **6000.6.0f1**, C#, URP 17.6, Input System 1.20, официальный OpenXR Plugin 1.16.1. Windows-сборка использует Direct3D 11.

## Быстрый запуск

1. Открыть этот проект в указанной версии Unity, дождаться импорта пакетов.
2. Открыть `Assets/StarPilot/Scenes/StarPilot_Demo.unity` или меню **STAR PILOT → Open Flight Demo**.
3. Нажать Play, затем **Начать / продолжить** или Enter.
4. Для сборки под Windows: **STAR PILOT → Build Windows Demo**. Запуск: `Builds/Windows/STAR PILOT.exe`.

Сцена генерирует кабину и окружение при запуске. Пустой вид Scene до Play ожидаем: корневой `DemoBootstrap` собирает прототип из модулей. Исходная `SampleScene` сохранена.

## Первое демо

Игрок находится в кресле SP-01 на орбите Кеплера. Можно свободно летать или пройти четыре пронумерованных маяка, начиная с подсвеченного бирюзовым. Движение через маяк засчитывается в направлении вперёд, внутри радиуса 15 м. После маршрута продолжается свободный полёт. Автоматической стыковки нет.

Версия 0.2: многослойная кабина со скошенными корпусами приборов, круглый навигационный дисплей, шкалы скорости и тяги, схема корабля, индикатор ориентации, физические переключатели и анимированные перчатки пилота. Экранные плашки уменьшены, основные показания находятся в кабине. Металл и обшивка получили карты рельефа и шероховатости, перчатки — швы и манжеты. Освещение включает затенение углублений, отражение окружения и мягкую подсветку панелей. Отражение кабины захватывается один раз при старте. Звёзды используют сглаженный профиль вместо мерцающих субпиксельных точек. Астероиды получили более плотную геометрию и текстуры камня; планета — карту поверхности, облака, отдельную атмосферу и ночные огни городов. У станции добавлены жилые секции, окна и стыковочный узел.

Конструкция, перчатки, шейдеры и звук созданы в проекте. Карты планеты: NASA Earth Observatory / Blue Marble и Black Marble. Камень, металл и обшивка: Poly Haven, CC0. Шрифт приборов: Rajdhani, OFL. Подробности и ссылки: [источники материалов](Docs/ASSET-CREDITS.md). Художественные модели всё ещё прототипные.

## Клавиатура и мышь

| Клавиша | Действие |
|---|---|
| W / S | Тяга вперёд / назад |
| A / D | Боковая тяга |
| R / F | Вертикальная тяга |
| Мышь, стрелки | Тангаж и рыскание |
| Q / E | Крен |
| Левый Alt + мышь | Осмотр кабины |
| Удерживать Tab + ЛКМ | Указатель мыши и физические переключатели |
| Пробел | Активное торможение |
| Левый Shift | Ускорение |
| T | Стабилизация |
| I | Двигатель |
| Backspace | Сброс корабля и маршрута |
| H | Подсказки |
| Escape | Пауза и меню |

В обычном режиме включены маневровые двигатели стабилизации: они плавно тормозят неуправляемые оси, а не мгновенно обнуляют скорость. При выключенной стабилизации корабль сохраняет поступательную инерцию. Вращение стабилизируется в обоих режимах для доступного управления. Тяга, тормоз и ориентация требуют включённого двигателя. Отключение двигателя не останавливает корабль.

Столкновения рассчитывает PhysX. Они повреждают корпус и вызывают событие с силой и локальным направлением удара. При разрушении корпуса требуется сброс. Хаптический жилет и его SDK пока не подключены.

## PC VR

1. Выполнить **STAR PILOT → Configure PC OpenXR** (сборка выполняет настройку сама).
2. Установить и запустить официальный PC runtime выбранного шлема; сделать его активным OpenXR runtime.
3. Подключить шлем, запустить демо и нажать **Запустить в VR**.

Шлем не нужен для запуска обычного режима: XR загружается только по запросу. При недоступном runtime меню показывает причину. Используется сидячая камера с отслеживанием головы; экранный HUD и постэффекты отключаются в VR, физические приборы остаются в кабине.

| Контроллер | Действие |
|---|---|
| Левый стик | Тяга вперёд / назад, вбок |
| Правый стик | Тангаж / рыскание |
| Правый / левый триггер | Вверх / вниз |
| Левый grip возле рычага | Захват тяги; движение рукой вперёд / назад |
| Правый grip возле рукоятки | Захват джойстика; наклон контроллера |
| Триггер возле переключателя | Нажатие переключателя / удержание кнопки |
| Нажать левый / правый стик | Тормоз / ускорение |
| Правая основная кнопка | Двигатель |
| Правая дополнительная кнопка | Стабилизация |
| Левые основная / дополнительная кнопки | Крен |
| Кнопка меню слева / Escape | Пауза / продолжение |

Настроены профили Touch, Index, Microsoft Motion, Vive и KHR Simple Controller. Не у всех контроллеров есть все перечисленные органы управления: окончательные привязки уточняются после выбора оборудования. Прохождение реального VR-теста и измерение комфорта обязательны перед показом в шлеме. Добавлено прямое взаимодействие с рычагами на OpenXR/Input System: grip в пределах 19 см захватывает рукоятку, отпускание возвращает управление стикам. Триггер в пределах 13 см нажимает ближайший переключатель; ENGINE и ASSIST переключаются, BRAKE и BOOST удерживаются. Руки следуют контроллерам, пальцы сгибаются по grip. При потере отслеживания рука скрывается и захват сбрасывается. Это контроллерные руки, не оптическое отслеживание пальцев. Используется собственный компактный адаптер, XR Interaction Toolkit пока не добавлен.

## Устройство проекта

- `Flight/ShipFlightController` — физика, помощь, состояние, события столкновений. Не зависит от VR и жилета.
- `Input/PilotInput` — адаптеры клавиатуры, мыши и XR-контроллеров.
- `Input/XrFlightMode` — запуск OpenXR и отслеживание головы.
- `Input/CockpitInteraction` — мышь и прямой захват органов управления контроллерами.
- `Presentation/CockpitControl`, `PilotHands`, `FlightInstrument` — переключатели, перчатки, векторные приборы.
- `Flight/FlightRoute` — последовательность маяков с проверкой пересечения плоскости.
- `Presentation` — реальные показания приборов, меню, синтезированный звук.
- `World` — модульное построение кабины, станции и окружения.
- `Resources/StarPilot` — собственные URP-шейдеры.
- `Diagnostics/DemoSmokeTest` — проверка физики в собранном приложении по специальному флагу.
- `Editor/StarPilotTools` — настройка OpenXR и сборка.

Пример запуска автоматической проверки: `"STAR PILOT.exe" -screen-fullscreen 0 -screen-width 1920 -screen-height 1080 -starPilotSmokeTest -testOutput "E:\STAR PILOT\Validation"`. Она проверяет разгон, инерцию, торможение, боковую тягу, вращение, сброс, прохождение маяка и столкновение; сохраняет JSON и несколько скриншотов. Это не тест VR-оборудования.

## Следующие этапы

1. Проверить удобство клавиатуры и мыши, композицию кабины и производительность на обоих ПК.
2. После выбора шлема — проверить OpenXR на оборудовании, подогнать позы рук и захватов, привязки и комфорт; при необходимости перенести взаимодействия на XR Interaction Toolkit.
3. Заменить временные модули финальной кабиной, добавить качественные звуки и эффекты.
4. После выбора жилета — официальный SDK и адаптер событий двигателя/столкновений. До этого использовать журнал событий.
5. Согласовать реальные функции бортового ИИ. Сейчас ИИ не заявлен и не имитируется запрограммированными репликами.

Если есть дизайнер: кабина в метрах, ось Unity Y вверх / Z вперёд; кресло с глазами на 1.62 м; свободный обзор вперёд; интерьер примерно 3.4 × 2.7 × 4.8 м. Рычаги и кнопки передавать отдельными объектами с корректными pivot, FBX, PBR-текстуры. Предварительный бюджет интерьера — до 100 тысяч треугольников, общие материалы, текстуры до 2K; уточнить после профилирования выбранного шлема. Приборы должны оставаться читаемыми без экранного HUD.
